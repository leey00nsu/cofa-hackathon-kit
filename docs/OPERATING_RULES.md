# 운영 규칙

2026-10-30에 사용자가 제공한 참가 안내·필수 확인 브리프·상세 가이드·Proctor 안내를 바탕으로 작성했다. 원문과 개인 응시 자료는 재배포하지 않는다. 실제 화면·최신 운영 안내·과제 README가 우선한다.

## 제공된 환경

- AI는 응시 환경의 Codex만 사용한다. 권장 표시명은 참가 메일의 **6.1 Sol, 5.6 Terra, 6.0 Luna**를 기준으로 확인한다. 모델 ID를 임의로 추정하지 않는다. Astra·Claude Code·별도 외부 모델·개인 API 키·개인 유료 구독은 사용하지 않는다.
- Codex 버전은 업데이트하지 않는다. 패키지 설치가 필요해도 Codex·플랫폼 설정·감독 연결 프로세스를 변경하지 않는다. 토큰과 CPU/RAM을 목적에 맞게 사용한다.
- 공개 저장소의 지침·스킬·하네스·템플릿·일부 코드를 Clone·다운로드해 사용할 수 있다. 활용한 저장소는 2차 결과 통지 전까지 Public을 유지한다. 비공개 자료·개인 PC 업로드·외부 자료를 통한 결과물 통째 교체는 허용되지 않는다.
- 문제·파일·결과물·작업 로그를 외부에 전송하지 않는다. Git Push·외부 이슈/PR·메신저·외부 분석/LLM 전송을 수행하지 않는다. 허용된 자료 가져오기와 구분한다.
- 필요한 정보는 플랫폼 안에서 AI로 습득한다. 참가자가 외부 브라우저에서 직접 자료를 열지 않는다.
- **Computer Use(자동 조작)는 전 단계 금지**다. Playwright·Puppeteer·Selenium 등으로 UI를 자동 조작하는 검증을 하지 않는다. CLI·단위 테스트·허용된 서버 요청 검증과 참가자의 수동 Browser 확인을 사용한다.
- 감독·차단·업로드 제한을 도구·경로·설정 변경으로 우회하지 않는다. 허용된 작업이 막히면 Cofa Helper 또는 문제 신고를 이용한다.

## 감독과 Browser

모니터 1대, 독립된 공간, 컴퓨터 웹캠, 충전 중인 Proctor 휴대폰, 전체 화면 공유를 유지한다. 휴대폰에는 손·키보드·얼굴·모니터가 함께 보이게 한다. 외부 키보드는 유선 1개까지이며 블루투스는 허용하지 않는다고 안내돼 있다. 신분증은 실물로 준비하고 가림 범위는 원본 Proctor 가이드로 확인한다. 화장실 안내는 당일 09:50 메일을 확인한다.

서비스는 `0.0.0.0`에 바인딩하고 실제 포트와 경로로 내장 Browser를 연다. 3000번은 고정 포트가 아니다. 서버 터미널은 유지한다. 임의 터널·외부 배포가 필요하다고 가정하지 않는다.

## 과제와 제출

2026-10-31 10:00~14:00 KST. 09:40까지 접속 준비. 과제 최대 180분, 서술형 6문항·문항당 5분이다. 준비 대기 약 5분 안내가 있으나 생성 화면은 최대 10분·재시도를 표시할 수 있다. 대기도 14:00 종료에 포함되며 휴식·검토 시간이 별도로 보장되지 않는다.

제출 전 필수 파일·저장 상태를 확인한다. 작업 종료 10분 전 제출 시작 권고를 따른다. 미리보기에는 일부 파일만 보일 수 있다. 확정하면 파일을 수정할 수 없고, 이후 실제 구현과 기록을 바탕으로 서술형 문항이 준비된다.

**예상 문답 생성·AI와의 연습·복습은 과제 제출물 확정 전에 끝낸다. 확정 이후에는 AI 사용을 중단한다.** 서술형에서는 AI와 복사·붙여넣기가 금지되며 직접 입력한다. 노트·코드 열람 가능 여부는 명시되지 않아 이를 전제로 하지 않는다. 실제 문항을 다시 AI에 보내 답변받는 기능을 만들지 않는다.

첫 문항은 시작 버튼, 다음 문항은 앞 답안을 제출한 순간부터 5분이다. 이전 문항으로 돌아가거나 확정 답안을 수정할 수 없다. 14:00 또는 각 제한시간 중 먼저 도달한 시점이 적용된다. 마지막 답안 후 최종 완료 화면의 제출 ID·시각·파일 수·크기를 확인한다.
