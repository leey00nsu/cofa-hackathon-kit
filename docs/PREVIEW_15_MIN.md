# 사전 체험 1회·15분

실제 응시 장소와 장비로 진행한다. 실제 문제 구현이나 범용 설치 작업에 소모하지 않는다.

| 분 | 확인 |
| --- | --- |
| 0~3 | 웹캠·전체 화면·Proctor 연결, 충전·한 모니터·촬영 구도 |
| 3~5 | README 열기, 파일 작성·저장, 터미널·권한 |
| 5~8 | 제공 Codex 응답, `/status`·`/model`, 허용 모델, 승인 대기와 실행 중 구분 |
| 8~10 | 공개 레포 Clone과 Python 버전, 스킬 인식·문서 접근 가능 여부 |
| 10~12 | 서버를 0.0.0.0에 실행, 실제 포트·경로로 내장 Browser 수동 확인 |
| 12~15 | Cofa Helper 사용법·제출 경로 확인, 체험 종료 후 예시 서술형 흐름 확인 |

체험 작업·예시 답변은 평가에 반영되지 않는다고 안내돼 있다. 체험 파일·환경이 본 과제로 유지된다고 가정하지 않는다. 사용할 수 없었던 명령·패키지만 기억하고, 실제 과제에서는 제공 환경을 다시 확인한다.

설치 QR은 휴대폰 앱 설치용, 응시 QR은 Proctor 앱에서 세션에 연결하는 용도다. 신분증·안경 확인은 본 과제 시작으로 녹화된 뒤 진행한다. 휴대폰은 촬영 구도에 고정해 둔다.

연결·권한·출력 오류는 Cofa Helper 또는 문제 신고로 문의한다. 체험 중에도 업데이트·외부 AI·자동 UI 조작·감독 설정 변경을 시도하지 않는다.
