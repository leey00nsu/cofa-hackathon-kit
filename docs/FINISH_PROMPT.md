# 제출 전 마무리 지시

**과제풀이 단계에서만 사용. 제출물 확정 후에는 실행하지 않는다.**

```text
$implementation-brief

새 기능 추가를 멈추고 최종 구현과 검증을 마무리하라.
공식 README의 필수조건과 .hackathon/REQUIREMENTS.md를 실제 파일·실행 결과와 대조하라.
중요한 실패는 수정하고 같은 검증을 다시 실행하라. 미구현·미검증·알려진 한계를 그대로 명시하라.
코드·고객 근거·결정·검증 기록을 기준으로 예상 질문·답변을 작성하라.

핵심 6개와 필요할 때 추가 6개까지, 각각 짧은 답변·설명·실제 파일/행/정확한 짧은 인용·검증 근거·한계를 포함하라.
실제 문항을 안다고 주장하지 말고, 없는 DB·API·패턴·성능·테스트·과거 의도를 지어내지 마라.
구현과 질문의 전제가 다를 때 어떻게 바로잡아 설명할지도 포함하라.

소스 지문과 근거 검사를 통과시킨 뒤 .hackathon/study/IMPLEMENTATION_QA.md와 LAST_REVIEW.md를 만들어라.
최종 코드가 바뀌면 문답과 근거도 다시 검토·갱신하라. 단순 지문 교체만으로 최신 검토를 했다고 하지 마라.
내게 핵심 6개를 내가 직접 설명할 수 있게 안내하고, 검증 결과와 제한을 짧게 알려줘.
제출 버튼·공식 화면은 조작하지 마라. 내가 복습을 마친 뒤 직접 제출한다.
제출 확정 이후에는 AI 사용을 중단한다.
```
