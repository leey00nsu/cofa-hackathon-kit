# 시작 지시

제공된 Codex 대화 입력창에서 `$grill-with-docs .hackathon/START_PROMPT.md를 읽고 시작 지시에 따라 진행해`라고 입력한다.

공식 README·과제 안내와 설치된 AGENTS.md를 읽고, [인터뷰 절차](INTERVIEW_PROTOCOL.md)를 적용한다. 제공 파일·필수 제출 경로·실행 방법을 확인한다.

실제 과제 지시서 경로와 참고 키트 폴더를 먼저 구분한다. 기존 작업이 있거나 ‘이어서 진행’ 요청이면 재초기화하지 말고 AGENTS의 재개 규칙과 기존 인계 메모·장부·파일을 대조해 다음 행동부터 이어간다. 기록만 보고 테스트 완료나 서버 상태를 추정하지 않는다.

참가자는 고객에게 질문을 전달하고 실제 답변을 중계한다. 기존 요구사항 정본은 설치 결과 또는 `.hackathon/install.json`의 `requirements_path`를 따른다.

먼저 담당자에게 전달할 열린 질문 1~3개와 각 답변이 구현에 미치는 영향을 제안한다. 이후 답변마다 사실·가설·남은 질문·지금 구현 가능한 범위를 갱신한다. 구현 전에는 [자동 검증](AUTOMATED_TESTING.md)을 읽고 진행한다.
